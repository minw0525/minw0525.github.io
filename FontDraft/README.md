# FontDraft

iPad·Apple Pencil을 위한 서체 스케치 웹앱. 펜·브러시·지우개로 그린 윤곽선을 노드 단위로 편집하고, 마스터와 배경 레이어를 관리합니다.

## 실행

```bash
npm ci
npm run dev
```

컴퓨터에서는 터미널의 Local 주소, 같은 Wi-Fi의 iPad에서는 사설 Network 주소로 접속합니다.

```bash
npm run build   # 배포 파일: dist/
npm test        # 설치된 Chrome으로 테스트
```

## 기본 조작

- 노드 탭: 선택. 노드 더블탭: smooth 전환. 세그먼트 더블탭: 해당 컨투어 선택.
- Shift: 선택 추가·10단위 이동·정방형 도형. Opt: 핸들 고정 노드 이동(smooth만 축선 제한), 핸들 각도 고정 이동. 화면 키는 탭 고정 또는 누른 채 사용합니다.
- 두 손가락: 패닝·줌, 두 손가락 탭: Undo, 세 손가락 탭: Redo. 손가락 도구 사용은 체크박스로 켭니다.
- 우상단 미리보기: 편집 화면만 검은 면으로 표시하며 편집은 계속 가능합니다. 하단 프리뷰는 현재 편집 레이어를 따릅니다.
- 컨투어 → 극점 추가: 선택한 컨투어에 적용하며 선택이 없으면 현재 레이어 전체에 적용합니다. 좌표는 정수로 반올림합니다.
- 컨투어 → 노드 복제: 같은 컨투어에 복제점을 추가합니다. 편집 → 복제는 별도 패스를 만듭니다.
- 리본 오른쪽 아이콘: 사이드패널 표시/숨김. 보기 → 사이드패널 왼쪽 배치: 조작부 위치 전환.

## 저장과 내보내기

파일 → 프로젝트 관리에서 이 브라우저에 저장된 프로젝트를 조회·열기·삭제할 수 있습니다.

작업은 IndexedDB에 자동 저장됩니다. 파일 → **프로젝트 백업 / 전체 프로젝트 백업**으로 원본 JSON을 보관하고, **백업 열기**로 복원하세요. 프로젝트 관리에서 영구 저장 허용 여부와 사용량을 확인할 수 있습니다. 사이트 데이터 삭제에 대비한 외부 백업은 별도로 필요합니다. **UFOZ**는 다른 폰트 에디터와 교환할 때 사용하세요. 문자열 전체를 **SVG·PNG**로 내보낼 수도 있습니다.

외부 UFO의 모든 기능을 지원하지는 않습니다. 컴포넌트·커닝 등 지원하지 않는 데이터가 있으면 열기를 중단합니다. TTF/OTF 생성·가져오기는 지원하지 않습니다.
