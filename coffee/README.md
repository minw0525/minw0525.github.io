# 브루 타이머

나만의 커피 레시피를 저장하고 추출 순서에 맞춰 사용할 수 있는 개인용 PWA 타이머입니다.

## 기능

- 여러 레시피 저장, 검색, 복제 및 편집
- 원두량, 물 온도, 드리퍼, 분쇄도와 메모 기록
- 단계별 시간과 물 양 안내
- 추출 경과 시간, 현재 누적 물 양과 다음 단계 표시
- 오프라인 실행과 홈 화면 설치

레시피는 브라우저에 저장됩니다. 별도의 계정이나 서버는 사용하지 않습니다.

## 실행

별도의 빌드 과정이나 패키지 설치가 필요하지 않습니다. 로컬에서 확인하려면 프로젝트 폴더에서 정적 파일 서버를 실행합니다.

```sh
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 열면 됩니다.

## 배포

프로젝트 파일을 GitHub Pages를 비롯한 정적 호스팅 서비스에 올릴 수 있습니다. PWA와 오프라인 기능을 사용하려면 HTTPS 환경이 필요합니다.

iPhone에서는 Safari로 배포 주소를 연 뒤 **공유 → 홈 화면에 추가**를 선택합니다.
